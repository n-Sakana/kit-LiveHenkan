Henkan

以前の版からの引き継ぎ
  別フォルダへ展開するときは、起動前に旧フォルダの user を丸ごと
  新フォルダへコピーしてください。辞書・候補学習・言語学習・設定を引き継げます。
  既存の user を上書きする前に、その内容を確認してください。
  旧版を終了してから install.bat を実行してください。旧右クリック登録は
  新しい登録に置き換わります。旧フォルダと user は削除されません。
  同じフォルダ全体を移した場合は user のコピーは不要です。
  書き込み不可の場所から使用した場合の退避先は以前と同じです。

ローマ字で打つそばから、漢字かな交じりの文に変わっていく日本語入力です。
変換にはこのフォルダにある小さな言語モデル xsmall.jinen を使い、すべてこのパソコンの中で動きます。
インストールもネット接続も要りません。このフォルダをまるごとコピーして使います。

■ 必要なもの
Windows 10 / 11（64-bit）。Windows に標準で入っている Windows PowerShell 5.1 と .NET Framework 4.8 で動きます。
追加の EXE / DLL、管理者権限は使いません。

■ はじめかた
1. install.bat をダブルクリックします。右クリックメニューに「Henkan」が増えます。
   （このユーザーの設定に登録するだけです。フォルダを移したときは、もう一度 install.bat を実行してください。）
2. デスクトップかフォルダーの何もないところを右クリック →「Henkan」→「Turn on」。
   Windows 11 では、右クリックのあと「その他のオプションを確認」の中にあります。
3. 2 秒ほどで画面に「Henkan オン」と出て、タスクトレイに「あ」のアイコンが出ます。
   あとは、ふだんのアプリでそのままローマ字を打ってください。

やめるときは、右クリック →「Henkan」→「Turn off」。タスクトレイのアイコンの右クリックからもオフにできます。
打ちかけの文があれば、表示のとおりに確定してから終わります。
登録を外すときは uninstall.bat を実行します（動いていれば止めてから外します）。

■ かな と 英数 の切り替え
変換キー              かな入力（Henkan）
無変換キー            英数入力（打ちかけの文は確定します）
半角/全角キー         かな と 英数 を切り替える
Ctrl + Shift + Space  設定で有効にすると切り替える（初期状態ではアプリの操作を優先）
タスクトレイのアイコンをクリックしても切り替わります。「あ」が かな、「A」が 英数です。

■ 打っている間
未確定の文には下線が付きます。打つそばから変換され、続きを打つと前のほうも文脈に合わせて変わります。
メモ帳のように文書の中へ書き込めるアプリでは、変換中の文字をそのまま文書の中に出します。
それ以外のアプリ（Word、Excel、ブラウザーなど）では、カーソルの位置に重ねて表示し、確定したときに文書へ入れます。
Enter               表示のとおりに確定する
Backspace           一文字戻す
Esc                 ひらがなに戻す。もう一度押すと打ちかけの文を取り消す
Shift + 英字        大文字で始まる英単語を元の綴りで入力する
文末の「。」「？」「！」のあと次の文を打ち始めると、前の文は自動で確定します。長い文は前のほうから順に確定します。
何も打っていないときの Space は全角の空白、Shift + Space は半角の空白です。
末尾の「ん」は n ひとつでも、確定や変換のときに「ん」になります（nn や n' でも入ります）。

■ 日付・時刻・数字を整える
変換中の文に、整えた形を先に表示します。確定した文は書き換えません。
  2026/10/17 → 2026/10/17（土）、2026年10月17日 → 2026年10月17日（土）
  11月3日 → 11月3日（火）、「11/2」「11／2」「11・2」→ 11/2（月）（2026年の例）
  午後3時半 → 15:30、9:05 → 09:05
  1234円 → 1,234円、1234.50円 → 1,234.50円
年月日、月日、時刻、円・人・件・個・台・枚・kg・km・% 付きの数字が対象です。
年を省いた日付は、変換を打ち始めた年として曜日を付け、年は表示しません。
「月日」や「年月日」、ハイフンで打った書き方は保ち、中点区切りはスラッシュに整えます。
単独の日付や金額なら Space / ↓ を一度押すと「元の形」に戻せます。
文の途中なら ← / → で対象を選んでから Space / ↓ を押してください。
選び直した形のまま確定します。整形を戻す操作は、単語の学習には使いません。
ID・番号・URL などと分かるもの、不正な日付、「3時台」「3時間」はそのままです。
単位のない数字は整えません。
文脈から区別できない日付形式の識別子は、元の形を選び直してください。
設定の「日付・時刻・単位付きの数字を整える」で止められます。
「数字を全角にする」を選んだ場合は、その設定を優先して整形を止めます。
句読点を自動で足す機能はありません。

■ 日本語と英語を続けて打つ
かな入力のまま、日本語のローマ字と英単語を続けて打てます。
例：kyouhagithubnipushshita → 今日はgithubにpushした
英単語は打った綴り・大文字と小文字を保持します。英文の途中の Space は半角の空白として入り、続けて英文を打てます。
日本語の途中の Space は候補選択です。英語の候補を選び直すときは、矢印キーで対象の語を選んでから Space を押します。
読みが日本語にもなる語や、知らない単語は、意図と違う言語になることがあります。
そのときは矢印キーで語を選び、F10 で英字、F6 でひらがなに直して確定してください。
たとえば apiwohiraku が「アピを開く」になったとき、← で「アピを」を選び F10 を押すと「apiを開く」になります。
確定すると語の言語を覚え、次回の判定へ反映します（設定の学習をオフにすると覚えません）。
この記憶は user\languages.tsv に保存し、設定の「忘れる」で候補の学習と一緒に消せます。

■ 変換を直す
Space / ↓           次の候補（候補の一覧が出ます）
Shift + Space / ↑   前の候補
1 〜 9              一覧の番号で選ぶ
PageDown / PageUp   一覧の次のページ / 前のページ
← / →               直すところ（文節）を移る。色の付いたところが対象です
Shift + ← / →       文節を短く / 長くする
Enter               確定する
Esc / Backspace     選び直しをやめて、打っている状態に戻る
候補には、登録した単語、ひらがな・カタカナ・半角カナ・英数の形、「きょう」「あした」「いま」などの日付と時刻も並びます。
選び直した候補は覚えて、次から先に出します（設定で止められます）。

F6 / Ctrl + J       ひらがな
F7 / Ctrl + K       カタカナ
F8 / Ctrl + ;       半角カタカナ
F9 / Ctrl + L       全角英数（もう一度押すと大文字、頭文字だけ大文字）
F10 / Ctrl + :      半角英数（同上）
Ctrl + H は Backspace、Ctrl + M は Enter、Ctrl + N / P は次 / 前の候補、Ctrl + B / F は文節の移動、Ctrl + I / O は文節を短く / 長く。

矢印キー以外の移動キーやショートカット、マウスのクリックなど文書を動かす操作をすると、打ちかけの文は表示のとおりに確定してから、その操作が行われます。

■ 単語を登録する
右クリック →「Henkan」→「Add a word」、またはタスクトレイのアイコンの右クリック →「単語を登録…」。
「よみ」をひらがなで、「単語」に出したい表記を入れて「登録する」を押します。
登録した単語は、文の中でその読みが一語として出てきたところに使われ、候補の一覧にも「登録語」として出ます。
読みだけを打ったときは、登録した単語がそのまま出ます（メールアドレスなどの決まり文句にも使えます）。
「読み込み」で、MS-IME や Google 日本語入力から書き出したテキスト（よみ・単語・品詞のタブ区切り）を取り込めます。
登録した単語は user\dictionary.tsv に入ります。ふつうのテキストなので、メモ帳で直しても構いません。外へは送りません。

■ 設定
右クリック →「Henkan」→「Settings」、またはタスクトレイのアイコンの右クリック →「設定…」。
半角/全角キーの扱い、Space・記号・数字の全角/半角、句読点の形、文末での自動確定、
変換中の文字を文書の中に出すかどうか、学習のオン・オフと消去を切り替えられます。
変えた設定はその場で user\settings.txt に保存されます。

■ 困ったとき
Ctrl + Shift + F12   いつでも、すぐに終了します（緊急停止）。打ちかけの未確定の文字は取り消します。
うまく始まらないときは、このフォルダの user\error.txt に理由が書かれます。
変換がおかしな形を覚えてしまったら、設定の「忘れる」で学習を消せます。

■ このフォルダに作られるもの
user フォルダ（登録した単語、学習、設定、開始・終了の記録）と temp フォルダ（起動時の一時ファイル）をこのフォルダの中に作ります。
ほかの場所には書き込みません。打った内容は記録しません。

■ 知っておいてほしいこと
正式な IME ではなく、キー入力を受け取って、文字をアプリへ送り込む方式です。
変換中の文字を文書の中に出すのは、メモ帳（Windows 11）と、リッチエディットという部品で作られた入力欄です。
  そこでは、確定するまでの書き換えは「元に戻す」の履歴に残らず、確定したひと続きが「元に戻す」1 回分になります。
  文字を選択した状態で打ち始めたときは、重ねて表示し、確定したときに選択を置き換えます。
  設定の「変換中の文字を文書の中に出す」をオフにすると、どのアプリでも重ねて表示します。
Word、Excel、ブラウザー、そのほかのアプリでは、カーソルの位置に重ねて表示します。
  書体や色は文書に合わせますが、行の折り返しには追従しません。
  アプリが書式を公開しない場合は大きさを推定します。カーソルの位置も取得できない場合は、ウィンドウ下部に表示します。
文書の中に変換中の文字が出ているときに、このソフトがタスクマネージャーなどで強制終了されると、
  その文字は未確定のまま文書に残ります（オフにしたときや緊急停止では残りません）。
パスワード欄と判別できるときは入力を加工せずに通します。アプリが情報を公開しない欄は見分けられないため、パスワードを打つ前に無変換キーで英数にしてください。
確定した文を選んで変換し直すこと、次に打つ語の予測、打ち間違いの自動修正はできません。
オンの間は Windows の IME をオフにします。ゲームや、キーを特別に扱うアプリではオフにして使ってください。
